# Security policy

## Supported versions

Only the latest release of this fork receives fixes.

## Reporting a vulnerability

Please report security issues privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) for this repository, and do not open a public issue.
Include the affected version, the Android ABI and API level, and a way to reproduce the problem.

Vulnerabilities in FFmpeg or in an external library should be reported to their own projects as well:
<https://ffmpeg.org/security.html>.
